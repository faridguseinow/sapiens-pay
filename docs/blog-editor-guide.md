# Bloq redaktoru və SEO bələdçisi

Hər yazıdan əvvəl hədəf oxucunu, onun axtarış niyyətini və əsas problemini müəyyənləşdirin. Əsas açar sözü və bir neçə yaxın mövzu terminini seçin, əsas cavabı girişin əvvəlində verin və yazının fərqli/praktik tərəfini aydınlaşdırın. Məqaləyə uyğun daxili xidmət və bloq keçidləri, etibarlı xarici mənbələr və bir konkret CTA planlaşdırın.

Oxucu üçün yazın; uzun, ümumi girişlərdən və açar söz təkrarından qaçın. Bölmələri `##`, alt bölmələri `###` ilə qurun. İddiaları etibarlı mənbə ilə əsaslandırın, saxta statistika və müəllif adı istifadə etməyin. Məzmun dəyişəndə onu yeniləyin; sistem ilkin yayım tarixini saxlayır və dəyişiklik tarixini ayrıca göstərir.

Redaktor təhlükəsiz Markdown alt-dəstini dəstəkləyir:

- qalın: `**mətn**`, italik: `*mətn*`
- daxili/xarici link: `[aydın keçid mətni](/az/services/...)`
- siyahı: `- element` və ya `1. element`
- sitat: `> sitat`
- məlumat bloku: `> [!INFO] mətn`
- xəbərdarlıq: `> [!WARNING] mətn`
- cədvəl: Markdown cədvəl sintaksisi
- CTA: `[CTA: Məsləhət al | /az#contact]`
- ayırıcı: `---`

Şəkil alt mətnində şəkildə həqiqətən görünəni qısa təsvir edin. Açar sözləri süni şəkildə alt mətnə doldurmayın. SEO sahələri boş qala bilər: başlıq, meta açıqlama və Open Graph məlumatları əsas məqalə sahələrindən avtomatik fallback alır. SEO checklist xəbərdarlıq üçündür və yayımı bloklamır.
