# Sapiens Mail server runbook

## Production host

- Hostname: `mail.sapiens-pay.com`
- Domain: `sapiens-pay.com`
- Operating system: Ubuntu 24.04 LTS
- Mail stack: Mailcow (Postfix, Dovecot, Rspamd, ClamAV)
- Application backend switch: `MAIL_BACKEND=self-hosted`

## Required DNS

Do not change the MX record until all preflight checks and parallel delivery tests pass.

- `A mail` → Contabo IPv4 (`DNS only` in Cloudflare)
- `MX @` → `mail.sapiens-pay.com` priority `10`
- `TXT @` → Mailcow SPF value
- `TXT dkim._domainkey` → key generated by Mailcow
- `TXT _dmarc` → staged DMARC policy
- PTR/rDNS for Contabo IPv4 → `mail.sapiens-pay.com`
- `CNAME autoconfig` → `mail.sapiens-pay.com`
- `CNAME autodiscover` → `mail.sapiens-pay.com`

## Application environment

Secrets belong in Vercel encrypted environment variables. Never commit them.

```text
MAIL_BACKEND=self-hosted
MAIL_SERVER_HOST=mail.sapiens-pay.com
MAIL_SERVER_USER=info@sapiens-pay.com
MAIL_SERVER_PASSWORD=<generated mailbox password>
MAIL_IMAP_PORT=993
MAIL_SMTP_PORT=465
MAILCOW_API_URL=https://mail.sapiens-pay.com
MAILCOW_API_KEY=<restricted read-write API key>
```

Keep `MAIL_BACKEND=resend` in production until the self-hosted acceptance tests pass.

## Acceptance checks

1. Forward and reverse DNS match.
2. Ports 25, 465, 587, 993, 80 and 443 are reachable as intended.
3. TLS certificates are valid and TLS 1.0/1.1 are rejected.
4. SPF, DKIM and DMARC pass at Gmail and Outlook.
5. Gmail, Outlook and Yahoo delivery tests succeed.
6. Inbound and outbound attachments are preserved.
7. IMAP folders, flags, moves, drafts, trash and full-text search work.
8. Mailcow API can create, disable and quota-limit a test mailbox.
9. A full encrypted backup completes and a test mailbox can be restored.
10. Resend remains available during a 24–48 hour observation window.

## Rollback

If acceptance fails after the MX switch, restore the previous Resend MX record and set `MAIL_BACKEND=resend`. Do not delete the Resend domain or credentials until the observation window is complete.
